# UK Retail Sales & Customer Analytics

## Project Overview

This project focuses on analysing retail sales and customer behaviour using a real UK online retail dataset.

The main goal is to understand how the business is performing, which products and customers contribute the most revenue, and what trends can be found in the sales data.

## Business Questions

During this project, I want to answer questions such as:

- How much total revenue did the business generate?
- How did sales change over time?
- Which products generated the highest revenue?
- Which customers spent the most?
- Which countries contributed the most sales?
- What is the average order value?
- How many orders were cancelled or returned?
- Which months had the highest sales?
- Which customers purchased most frequently?
- What useful business insights can be found from the data?

## What I Will Do

For this project, I will:

- inspect the raw dataset
- clean and validate the data
- prepare the data for analysis
- use MySQL for SQL analysis
- use Python and Pandas for deeper analysis
- create KPIs and business metrics
- build an interactive Tableau dashboard
- summarize the key findings and recommendations
